# Windows Environment (agent operating rules)

## Shell rules

- End user machine: Windows 10/11, PowerShell only. No WSL, no bash, no Docker.
- Agent runs commands via `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <script>`
  or `-Command "<one-liner>"`. Long installs: allow generous timeouts
  (Install 20 min, Download-Models 60 min, dotnet build 5 min).
- All committed `.ps1` are ASCII-only + UTF-8 BOM (Windows PowerShell 5.1 mis-parses
  BOM-less non-ASCII as mojibake). Keep this invariant when editing scripts:
  ASCII text, then add BOM. Parse-check after edit:
  `[System.Management.Automation.Language.Parser]::ParseFile(<path>, [ref]$null, [ref]$e)`.
- PowerShell quirks that bit us (do not rediscover):
  - `$args` is an automatic variable — never assign it ($ComfyArgs instead).
  - `$PSScriptRoot`, not `$PSSplitPath`; repo-root scripts use
    `$RepoRoot = Split-Path -Parent $PSScriptRoot`.
  - After winget installs, PATH changes need a NEW process; scripts return exit 2
    to signal reopen-and-rerun.
- Repo layout (the contract; recreate exactly):

```text
<repo root>/
  runbook.md            base setup doc (EN)
  runbook_2.md          video-model doc (EN)
  README.md             Hungarian user guide
  AGENTS.md             agent contract
  scripts/*.ps1|bat     committed automation (see SKILL.md)
  workflows/*.json      committed template workflows (H3 + LTX-2.5)
  .agents/comfyui-setup/  this skill
  tmp/                  LOCAL-ONLY (git-ignored): ComfyUI clone+venv, SwarmUI clone+build, Data
  models/               LOCAL-ONLY (git-ignored): 12 safetensors, ~86 GB
```

- Port map: 7801 SwarmUI web | 7821 backend comfy (Swarm child) | 8188 direct comfy
  (optional, independent). Listeners: 7801 = SwarmUI.exe, 7821 = python (venv).
- Graft FDS notes: `tmp/SwarmUI/Data/Backends.fds` — tab-indented FDS, one numeric
  section per backend, `settings:` keys must match Swarm's ComfyUISelfStartSettings.
  Real verified file used `ExtraArgs: \x` (literal). Write it ONLY before first
  SwarmUI launch (or stop Swarm first); verify with Verify-Setup "swarm graft" row.
- Model profiles (two committed in `scripts/Download-Models.ps1`): `friend` = 8GB LTX
  stack ~23GB (GGUF Q3_K_M DiT + w4a8 Gemma4 encoder + VAEs + upscaler + duration
  head); `full` = 16GB reference manifest ~86GB incl. H3 (runbook_2 sec.7).
  Verify-Setup is profile-aware. Downloadable extras catalog: `MODELS.md` (repo root).
- ComfyUI-Manager is a pip package (installed via `manager_requirements.txt`), NOT a
  custom_nodes clone. ComfyUI itself is cloned to `tmp/ComfyUI` (never into
  custom_nodes). SwarmUI cloned to `tmp/SwarmUI` (never into ComfyUI/custom_nodes).
- Model-path wiring: `tmp/ComfyUI/extra_model_paths.yaml` (generated by
  Download-Models.ps1, machine-local absolute base_path, never committed). The Swarm
  backend comfy reads it too — models appear in node dropdowns even if Swarm's own
  model browser is empty. Optional: surface models in Swarm UI via Server
  Configuration → Paths (human clicks, agent instructs; not required for workflows).

## Troubleshooting map

| Symptom | Fix |
|---|---|
| `python/git: not recognized` | reopen shell; Preflight re-run; PATH checkbox reinstall as last resort |
| `winget: not recognized` | old Windows: manual downloads (URLs in Preflight fatal message) |
| `Torch not compiled with CUDA enabled` | `pip uninstall torch` in venv, reinstall cu130 line (runbook §5), update driver |
| HF download 401/403 | token missing/expired or Agree-and-Access not clicked → re-gate; verify with API 200 |
| HF download interrupted | re-run same command; resumes in place |
| pip asks for Visual Studio/compiler | wrong python or wrong index-url; use venv + cu130 line only |
| Port busy (7801/7821/8188) | another instance running — use it or kill via Task Manager (`python.exe main.py`, `SwarmUI.exe`) |
| Swarm backend red / crash loop | View Logs on backend card; usually transient first-boot pip staging; Restart All Backends |
| SwarmUI build fails | delete `tmp/SwarmUI/src/bin/live_release`, re-run Install-Swarm; check dotnet SDK present |
| `extra_model_paths.yaml` ignored | only loaded at comfy start; restart backend/direct comfy after regenerating |
| Verify-Setup FAILs elsewhere | treat FAIL rows as the resume pointer; fix top-down |
